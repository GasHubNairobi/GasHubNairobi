GASHUB DEALER APPLICATIONS — ADMIN > DEALERS

Changes in this patch:
- Dealer applications are shown inside admin-dealers.html, above the existing dealer directory.
- The separate Dealer Applications sidebar item is removed from Admin > Dealers.
- The panel lists requests, opens complete application details, shows the business coordinates/map link, and supports Approve, Decline, and Ignore/Archive.
- Approving creates a dealer user with one-time credentials, sends them by configured SMTP email, requires first-login onboarding/password change, and creates the dealer inactive and unverified. Verification is separate and is never automatically awarded.
- Application controller uses public.dealer_applications statuses pending/approved/rejected/ignored and the linked_user_id, linked_dealer_id, temporary_credentials_sent_at and first_login_required fields.

Install:
1. Back up the project. Copy the updated admin/admin-dealers.html, admin/admin-dealer.css, admin/admin-dealer-applications-panel.js, and backend/controllers/dealer-application-controller.js into your project.
2. Keep admin-auth.js, admin-login.html/js/css and admin-main.js unchanged; this patch does not change admin credentials or login logic.
3. Ensure backend/routes/admin-routes.js registers GET /dealer-applications, GET /dealer-applications/:id, and PATCH /dealer-applications/:id/review behind requireAdmin, and server.js registers POST /api/dealer-applications. These routes exist in the included source project.
4. Ensure SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_FROM and APP_BASE_URL are set. Without SMTP configuration, approval is blocked and no account is created.
5. Run backend/dealer-first-login-migration.sql and, only if needed, backend/dealer-application-review-columns.sql in Supabase. Review existing schema and foreign-key ID types before running additive migration.
6. Restart the backend and hard-refresh Admin > Dealers.

Note: Database/email behavior cannot be live-tested from this archive. Check your actual Supabase column types and SMTP configuration before approving a real application.
