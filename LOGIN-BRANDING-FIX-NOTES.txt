GasHub dealer login / application fixes

- Dealer login now loads the existing GasHub logo, favicon, and watermark from dealer/images/.
- Dealer application page now shows the GasHub logo, favicon, and watermark using frontend/images/.
- Both dealer-login registration links now open /dealer-application.html, the reviewed application workflow.
- The legacy /dealer/dealer-register.html page redirects to the official application form.
- Dealer login backend now accepts email, generated username/user_code, dealer code, or phone number (normalizing phone punctuation).

Dealer credential reminder:
- Use the exact one-time username and temporary password from the approval email, not the administrator password.
- The temporary password is single-use. Successful initial login routes the dealer to first-login setup.
- The dealer account must exist in public.users and public.dealers and its user role/status must permit login. If credentials still fail, check the backend log and Supabase row for that specific dealer; do not manually change password_hash to plaintext.
