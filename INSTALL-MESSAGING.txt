GASHUB - ADMIN MESSAGING UPDATE
================================
Copy every file in this zip into your GAS HUB folder, keeping the same folders (replace when asked).

1) DATABASE (once)
   Supabase > SQL Editor > run  backend/messaging-migration.sql

2) .env  (add these lines, then restart the server)
   SMS_PROVIDER=africastalking
   AT_USERNAME=your-africastalking-username
   AT_API_KEY=your-africastalking-api-key
   AT_SENDER_ID=            (optional approved sender name)
   AT_SANDBOX=false         (true while testing in the Africa's Talking sandbox)
   Email uses the SMTP_* settings you already have.

3) Restart:  cd backend  &&  npm start
