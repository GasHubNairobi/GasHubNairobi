GASHUB DEALER FIRST-LOGIN FEATURE PATCH

1. Copy the folders/files in this patch over the matching files in your current GasHub project.
2. Open Supabase SQL Editor and run backend/dealer-first-login-migration.sql once.
3. Restart the backend server.
4. Sign out of the admin panel and sign back in, especially if the server was restarted (admin sessions are held in server memory).
5. In Admin > Dealers, create a login using a username and temporary password (8+ characters).
6. Dealer signs in once at dealer/dealer-login.html. The first login redirects to dealer-first-login.html.
7. Dealer fills the required details and chooses a new username/password. The temporary password is then permanently rejected.

Important: if the dealer consumes the one-time password but closes the browser before finishing setup, an administrator will need to issue a fresh initial login. The current admin page does not yet have a dedicated reset/reissue button.

This patch includes only files relevant to the dealer creation / onboarding flow, not the entire project. JavaScript syntax checks passed. Live Supabase integration could not be tested from this environment.
